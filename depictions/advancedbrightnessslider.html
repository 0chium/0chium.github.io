AdvancedBrightnessSlider Continued

1.2.4-1 · Rootless · Free · GPL-3.0

Go beyond minimum brightness.

Available to try on iOS/iPadOS 17 through 26 with a compatible rootless jailbreak. No Dopamine-only requirement. Tested configurations are listed separately; other combinations need testing.

Adjust brightness and extra dimming with the same Control Center slider. Above your chosen threshold, it controls normal brightness. Below it, Apple's native Reduce White Point dims the screen further while brightness stays at minimum.

Add to SileoSourceSupport

Your preferred balance

Start with the default 30% split, or open AdvancedBrightnessSlider Continued in Settings and adjust Threshold. Threshold changes apply automatically.

The Settings pane requires PreferenceLoader and Cephei Tweak Support. This package replaces the original AdvancedBrightnessSlider and retains existing preferences. Let Sileo handle the replacement.

Known limitations

  • On iOS 26.0.1, Settings does not show the Threshold slider’s numeric value. Preview isolation has not received a separate focused device test.
  • All minor and patch versions within iOS/iPadOS 17–26 are allowed to try. Other configurations still need testing.
  • Auto-Brightness suppression retains the existing implementation; its native-service effectiveness is not independently verified.
  • Accessibility White Point changes may affect the screen without repositioning Control Center.
  • Controlled disablement conditionally restores borrowed settings. Crash, SpringBoard restart or removal cannot guarantee cleanup; system settings may remain changed.
  • The legacy iOS 16 path is retained but this rebuilt release is not runtime validated there. Modern alternative Control Centers are not claimed as supported.
